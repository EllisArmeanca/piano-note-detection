Frontend-Backend application in order to detect piano notes and generate a piano sheet based on a '.wav' recording, high-quality, and monophonic. 

RUN THE APPLICATION: 
- frontend: npm run dev.

- backend: python app.py. 

The samples mentioned in the thiesis are located in the "samples" folder.

The Yin Method can be run by typing: python yinMethod.py. 
(but beforehand you should type in the file the audio file path in the first lines of the code)
